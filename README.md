# NutriFlow AI — Smart Meal & Supply

Aplicação web desenvolvida para planejamento nutricional inteligente e gestão financeira de compras, integrando orquestração multi-agente, engenharia de prompt e análise de dados.

## O que a aplicação faz
- **Cálculo Metabólico Inteligente:** Agente nutricional que interpreta objetivos e restrições alimentares para estruturar planos personalizados.
- **Otimização de Compras (Supply):** Converte o cardápio semanal em uma lista de supermercado organizada e otimizada.
- **Análise de Dados com IA:** Calcula indicadores financeiros e nutricionais em tempo real, como custo por grama de proteína e aderência ao orçamento.
- **Integração e Automação:** Permite exportar a estrutura de dados via Webhook para fluxos automatizados (n8n / Make).
