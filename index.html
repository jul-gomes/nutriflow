🔍 Como o NutriFlow Orquestra os Dados

Inspecione o pipeline de agentes, personalize as instruções (System Prompt) ou copie o fluxo pronto para automatizar seus pedidos no n8n e Make.

1. Agente Nutricionista (Cálculo Metabólico & Restrições) Interpreta objetivo e alergias/preferências, define calorias diárias e distribui proteínas, carboidratos e gorduras em 4 refeições práticas.
2. Agente de Compras & Delivery (Supply Matching) Converte os ingredientes do cardápio em uma lista semanal de supermercado com preços médios reais e sugere marmitas/pratos prontos equivalentes.
3. Agente Analista de Dados (Auditoria Financeira) Cruza o custo da cesta com o teto semanal definido pelo usuário, calcula o custo por grama de proteína e estima o percentual de economia.

Importe este fluxo no n8n para receber a lista via Webhook, processar com Claude/GPT/Gemini e enviar no WhatsApp:

{
  "name": "NutriFlow - Lista de Compras Automática",
  "nodes": [
    { "name": "Webhook NutriFlow", "type": "n8n-nodes-base.webhook", "parameters": { "httpMethod": "POST", "path": "nutriflow" } },
    { "name": "Agente IA (Claude / GPT / Gemini)", "type": "n8n-nodes-base.httpRequest", "parameters": { "method": "POST" } },
    { "name": "Estruturar Dados & Custos", "type": "n8n-nodes-base.code" },
    { "name": "Enviar Resumo WhatsApp", "type": "n8n-nodes-base.whatsApp" }
  ]
}
